# Template Collections & Resources

## Curated Lists
- **awesome-ascii-animation** — Animation-specific: https://github.com/mu-ct/awesome-ascii-animation
- **awesome-ascii-art** — General, massive: https://github.com/moul/awesome-ascii-art
- **awesome-ratatui** — Rust TUI apps/libraries: https://github.com/ratatui/awesome-ratatui

## Installable Collections
- **Asciiville** — Massive ASCII art/animation gallery with viewer. Includes flip-books, animated storyboards, curated art sets.
  https://github.com/doctorfree/Asciiville
- **arttime** — Curated ASCII/ANSI/UTF-8 art with flip-flop animation + storyboards. Also a clock/timer.
  https://wiki.archlinux.org/title/ASCII_art

## Font Collections (for text banners)
- **cmatsuoka/figlet-fonts** — Largest collection (C64, BDF, CJK, international, MS-DOS): https://github.com/cmatsuoka/figlet-fonts
- **xero/figlet-fonts** — Curated hacker aesthetic: https://github.com/xero/figlet-fonts
- **figlet.org** — Official font library: http://www.figlet.org/

## Classic Archives
- **16colo.rs** — Premier ANSI/ASCII art archive (BBS era groups): https://16colo.rs
- **Lospec Textmode Gallery** — Modern textmode art: https://lospec.com/gallery/tag/textmode
- **Demozoo** — Demoscene productions database: https://demozoo.org
- **asciimation.co.nz** — Classic Star Wars in ASCII: http://www.asciimation.co.nz

## Spinner Presets
- **cli-spinners** JSON — 100+ spinner patterns, cross-language: https://github.com/sindresorhus/cli-spinners
- **Silejonu/bash_loading_animations** — Bash spinner functions: https://github.com/Silejonu/bash_loading_animations

## Gold Standard Examples
- **GitHub Copilot CLI** — Animated ASCII banner (open source). Engineering blog: https://github.blog/engineering/from-pixels-to-characters-the-engineering-behind-github-copilot-clis-animated-ascii-banner/
- **fastfetch** — Logo database with GIF support: https://github.com/fastfetch-cli/fastfetch
- **Gifetch / brrtfetch** — GIF → animated ASCII for system info: search GitHub
